# Add a rule to allow ssh access
To add a rule to allow SSH access on AWS, navigate to your EC2 security group settings, go to the "Inbound rules" tab, click "Add Rule", then set the "Type" to "SSH", "Protocol" to "TCP", "Port Range" to "22", and specify the source IP address (either "My IP" for your current connection or a custom IP range) in the "Source" field. 
Key steps:
Access Security Groups: Go to the AWS Management Console, navigate to EC2, then select "Security Groups". 
Select Group: Choose the security group associated with the EC2 instance you want to allow SSH access to. 
Edit Inbound Rules: Click on the "Inbound rules" tab and select "Edit inbound rules". 
Add Rule: Click "Add Rule". 
Configure Rule:
Type: Select "SSH" 
Protocol: TCP (automatically set when choosing SSH) 
Port Range: 22 (automatically set when choosing SSH) 
Source:
"My IP" to allow access from your current IP 
Custom IP address or range in CIDR notation
